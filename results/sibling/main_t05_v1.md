## 1. 设置

- 模型：LLaDA2.0-mini，加 LoRA（r=32，挂在注意力的 qkv 和 dense 上），学习率 2e-5。
- 训练数据：MATH train。每次更新 4 题（2 个进程 × 每进程 2 题），共 500 次更新、2000 题。
- 采样：τ=0.5，T=0.9，每题最多采 8 次，取第一条答对的 rollout。
- 训练目标：在提交了 ≥2 个 token 的步上，teacher = 冻结的原始模型（揭示同组的其他 token，被评估的那个 token 保持掩码，即 LOO），得到 q。
  - 目标分布：t(c) = q(c)（τ=0.5 时 α=0）；其他 token 截顶到 0.49，多出的概率均匀摊到整个词表。
  - 损失：KL(t‖p)，加 0.1 × KL(p₀‖p)（作用在同一块里其余的掩码位置上，p₀ 为原始模型的分布）。
- 选 checkpoint：在 dev_fast 前 128 题上、τ=0.5 下，取准确率最高的 checkpoint。
- 解码协议：DMax，block 32，最长 2048 个 token。

## 5. 结论

1. **提速是真实的，并且能迁移到未训练过的高阈值**：τ=0.95 下解码步数减少 33%，准确率不降（+1.4 个点，不显著）。
2. **在训练用的 τ=0.5 上没有达到"加速且不掉点"**：准确率 −3.8 个点（p=0.11，不显著），截断率几乎没变（38.6% → 36.4%）。Phase 0 中丢分几乎全部来自截断，这个问题没有被解决。
3. **训练没有改变冲突结构**：不动点比例（约 0.93）和 q(c)<0.5 的比例（约 0.08）在 500 次更新中都没有下降。KL(t‖p) 在 100 步后就停在约 0.30。student p(c) 只从 0.85 升到 0.87。与此同时锚定项 KL 从 0.15 升到 0.4，模型在逐渐偏离原始分布。
4. 解读：这个目标是在 τ=0.5 的状态上**逐个 token** 地向 LOO 分布靠拢，没有任何一项告诉模型"在 τ=0.95 下这一整组 token 也应该一起提交"。τ=0.95 的提速更像是模型整体变自信带来的副作用，而不是学到了快速解码路径。这是下一版方案（`doc/plan_path_opsd.md`）要解决的问题。
5. **还缺关键对照**：原始模型直接调低阈值也能提速。需要在同一个 TPF 下比较准确率，也就是比较两条准确率–TPF 曲线。阈值扫描已提交：Vista job 1127239（τ = 0.9/0.8/0.7，原始模型和 step 375 各一遍，结果写入 `eval/sweep.json`）。结果出来后补到本文第 6 节。

## 5.1 为什么 τ=0.5 掉点、τ=0.95 反而涨点（逐题分析，2026-11-06）

评测配置已核对：两边都是贪心解码（T=0）、阈值相同、最长 2048，唯一区别是有没有 LoRA。（训练 rollout 用的是 T=0.9 采样。）

| | τ=0.5 原始 | τ=0.5 step 375 | τ=0.95 原始 | τ=0.95 step 375 |
|---|---|---|---|---|
| 每步平均提交 token 数 | 5.43 | **8.28** | 2.54 | **3.59** |
| 截断率 | 38.6% | 36.4% | 27.0% | 23.2% |
| 正常结束的题中的准确率 | 91.5% | **82.7%** | 97.0% | 95.1% |
| 重复类乱码（每万字符） | 6.3 | **9.0** | 0.14 | 0.54 |
| 改对的题中，原始模型截断的 | | 36 / 55 | | 30 / 35 |
| 改错的题中，训练后截断的 | | 36 / 74 | | 14 / 28 |

1. **同一个 τ，训练后的模型更激进**：它整体变自信了，同样的阈值下每步多提交约 50% 的 token。所以按同一 τ 比较，并不是在同等激进程度下比较。
2. **τ=0.95：多出来的激进落在安全区。** 原始模型在 0.95 下偏保守，丢分主要来自截断（长时间反复纠结）。训练后的模型更果断、输出更短，截断减少；改对的 35 题里有 30 题原本是截断。代价是正常结束的题准确率小降（97.0 → 95.1）。
3. **τ=0.5：多出来的激进落在危险区。** sibling 乱码增加约 40%，并出现一种新的失败方式：**写完了、但答案错**。训练后的模型有 55 题正常结束但答错，原始模型只有 26 题。改错的题里，有 38 题是训练后模型正常结束但答错，其中一半的末尾其实出现了正确答案，只是最终答案被同步提交的 token 弄坏了，例如：`$$$$ boxed{-{-50`、`\$\$33`、`\$33 − \$15 = \$118`、`\boxed{\left(3,frac{\pi}{2}\right)}`。
4. **两边是同一个效应**：模型变锐，导致同一 τ 下更激进。这个效应落在准确率–TPF 曲线的平坦段（0.95 附近）就表现为涨点，落在陡峭段（0.5 附近）就表现为掉点。
5. **训练目标没有实现"τ=0.5 不掉点"的原因**：目标主要是把已提交的 token 往 q 上推（q(c)≈0.90 > p(c)≈0.85），截顶只在约 5% 的位置上生效，而且只用答对的 rollout。冲突抑制那一侧太弱，净效果是整体锐化，冲突率（约 0.93 的不动点比例）一直没降。也就是说，**缺少直接惩罚不协调 sibling 的项**。
