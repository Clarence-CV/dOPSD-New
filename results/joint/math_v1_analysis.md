# Joint MATH v1：结果、实际流程与下一步

2026-10-17。依据 `outputs/joint_math_v1/` 的实际配置、逐题评测、训练日志、保存的自然轨迹与候选参考，以及当前 `selective_draft/joint.py`。本次仅做本地产物分析，没有启动模型训练或评测。以下扩展 Receiver 监督是建议，尚未实现或验证。

## 1. 目前成立的结论

这是一次有实际速度收益的初试；准确率基本保持，数值上增加 0.6 个百分点，尚不能认定有稳定准确率提升。

| MATH-500，同一 500 题、greedy、阈值 0.9 | 原始 LLaDA | Joint | 只读出、不注入 |
| --- | ---: | ---: | ---: |
| 答对数 | 172 | 175 | 172 |
| 准确率 | 34.4% | 35.0% | 34.4% |
| 每题平均步数 | 100.422 | 82.232 | 100.422 |
| 每题平均实际耗时 | 5.533 s | 4.927 s | 5.934 s |
| 每题 fallback 步数 | 51.300 | 31.634 | 51.300 |
| 每题有效生成 token | 244.096 | 244.500 | 244.096 |

Joint 步数减少 18.1%，实际耗时减少 11.0%。只读出与原始模型 500/500 输出逐字相同。配对有 32 题错→对、29 题对→错，净增加 3 题，配对检验 p≈0.80。前 200 题是 41.0%→39.5%，后 300 题是 30.0%→32.0%，也不支持将这次小幅变化解释为稳定能力提升。

评分沿用现有答案抽取和规范化字符串匹配，32/29 中混有表达形式变化，例如 `1.2` 与 `6/5`、`4/9` 与 `8/18`。这里保留原始分数，不将每次评分翻转都当作推理能力变化。

## 2. Teacher、Student，以及这次究竟训练什么

- Teacher：冻结的原始 LLaDA-8B-Instruct，不启用 readout/injector 引导。
- Student：同一份冻结 LLaDA，加上冻结的 L28 readout 和可训练的共享消息注入器。
- 本次训练：只更新注入器的 786,432 个参数；主干、embedding、LM head、readout 均冻结。没有训练 LoRA，也没有更新 Teacher。
- Readout：复用前次训练的 524,288 参数模块。之前通过原模型同一 MASK 状态下的末层分布蒸馏，使 L28 能提前给出较可用的 token 分布；本次不重新训练它。

注入器是 rank 64 的两层 MLP，对选中位置共享参数：

\[
m_i=\sum_v r_i(v)E(v),\qquad
h_i'=h_i+J_\phi(h_i,m_i).
\]

每个位置的注入器直接读取自己的 hidden 和自己的 soft draft；位置之间通过后续 L29–32 的双向 attention 交换消息。双向 attention 原本就存在，本方法额外提供了由 draft 得到的 token 身份信息。所有 soft message 都在注入之前计算，然后同时注入。

这里没有单独学习一个所有 token 共用的离散隐变量。“共同模式”是训练时选定的一整组参考 token；希望共享参数和后续 attention 学会向这种兼容的组合靠近。

## 3. 不动点是什么

给定真实去噪状态 x，其中已经提交的 token 固定，其余位置为 MASK。G 是当前 block 内按 L28 draft 置信度选出的最多 4 个通信位置。

一个候选组合记为 π=(π_i)_{i∈G}。预测 i 时，给冻结 Teacher 揭开 G 中除 i 以外的候选 token；i 自己仍是 MASK，其他 MASK 不变。得到：

\[
q_i^\pi(v)=Q_i\bigl(v\mid x,\;G\setminus\{i\}=\pi_{-i}\bigr).
\]

如果每个位置都满足

\[
\arg\max_v q_i^\pi(v)=\pi_i,
\]

π 就是这里的 Teacher 坐标不动点：**其他人采用这组选择时，每个人仍赞成自己的选择。**

两位置的例子是：候选为 (a,b)，给 Teacher 看 b，它在第一个位置仍选 a；给它看 a，它在第二个位置仍选 b。这是相互支持的局部组合。任务正确性另外来自整条续写的答案验证；相互支持本身不能证明答案正确。

不动点认证只在训练侧做。推理没有循环求解不动点，也不保证 Student 每次输出都满足该条件。

## 4. 实际训练和推理流程

每次训练更新，每张卡取一题：

1. 当前 Student 用 T=0.9 生成自然轨迹，随机抽最多 4 个可通信状态；自然轨迹答对或答错都可用。
2. 对每个状态，从完全相同的已提交 token/MASK 状态续写 8 次，T=0.9。8 次是每个状态的 continuation 预算。
3. 保留最终答案验证通过的完整续写，取它们在 G 上的整体 tuple 并去重。
4. 按候选 embedding 与当前 soft message 的平方距离排序；依次做上述留一认证，选第一个全部位置通过的共同参考。没有合格参考就跳过状态。
5. Student 只看原始 x 和自己的 draft。Teacher 额外看到参考中的同伴身份；这就是本版 PI。
6. 最小化组内完整词表 forward KL，只反传更新共享注入器：

\[
\mathcal L_G=\frac{1}{|G|}\sum_{i\in G}\operatorname{KL}(q_i^\pi\|p_{\phi,i}).
\]

所有位置使用同一个共同参考，避免从不同续写里分别挑标签。硬参考不输入 Student。每次更新重新采集 on-policy 状态。

本次 lr=1e-4，Adam betas=(0.9,0.99)，weight decay=0.1，grad clip=0.2，100 次优化器更新；3 卡，每卡每轮一题、最多四状态。

推理每个去噪步：

```text
当前 MASK 状态
  → L1–28
  → L28 readout 选最多 4 个位置，计算各自 soft message
  → 同时注入这些位置
  → L29–32 attention 传播，得到末层预测
  → 当前 block 内所有 confidence > 0.9 的位置同时提交
    （没有达标位置则提交最自信的一个）
  → 下一步
```

推理 greedy，最大生成 256 tokens，block 长度 32。通信集合 G 不等于最终提交集合：组员可以等待，组外位置也可以提交。推理不生成 8 个候选、不访问 Teacher、不做认证。

## 5. 为什么首先体现为加速

真实评测步数可直接分解：

| 每题平均 | base | joint | 差值 |
| --- | ---: | ---: | ---: |
| 没有位置过阈值、只能 fallback 的步 | 51.300 | 31.634 | −19.666 |
| 正常阈值提交的步 | 49.122 | 50.598 | +1.476 |
| 总步数 | 100.422 | 82.232 | −18.190 |

因此，主要观测是少了很多只能单位置推进的 fallback 步。答案长度几乎不变。每步平均耗时反而从约 55.1 ms 增到 59.9 ms（按总耗时/总步数计算），但步数收益抵消了增加的计算，得到 11% 净加速。

训练参考提供了直接的数学解释：通过认证的 2,019 个目标位置中，Teacher 对参考 token 的概率中位数为 0.9984，81.5% 超过 0.9。forward KL 对 Student logit 的导数是

\[
\frac{\partial\operatorname{KL}(q\|p)}{\partial z_v}=p(v)-q(v).
\]

当 q 接近参考 token 的 one-hot 分布，损失接近 −log p(参考)。Student 会被推动着更确信共同参考，因而更容易过 0.9 阈值。理想 one-hot 情形下，单位置损失低于 −log(0.9)≈0.105，就足以让该参考 token 超过阈值；这是说明机制的局部关系，不代表当前平均 loss 已给出整条生成保证。

这也有纠正身份的可能：参考与 L28 draft argmax 的一致率只有 71.4%。但它比较的是早层 draft 与条件 Teacher，不能当成“最终预测纠错 28.6%”。

可以确认训练后的注入改变了行为，并带来净加速；尚不能拆分认定不动点筛选、候选距离选择、同伴消息分别贡献多少。特别是有正确续写的状态中 66.3% 只有一个去重 tuple，多候选选模在这些状态没有选择空间。

## 6. 准确率为什么只小涨

第一，修复与损伤几乎抵消。存在实际推理改善，例如 test-8 正确处理坐标差、test-55 正确推出多项式次数；也存在实际退化，例如 test-32 把三人的内部排列数从 3!=6 改成 3。不能把效果全归于格式或全归于变自信。

第二，有效训练量很小。虽然配置训练集有 6,000 题，本次实际访问 327 题，只有 178 题贡献了合格参考：

| 项目 | 数量 |
| --- | ---: |
| 尝试状态 | 1,308 |
| 至少一条正确 continuation | 587 |
| 通过认证并用于训练的状态 | 525 |
| 组内被监督的 token 位置 | 2,019 |

自然轨迹原本答对的 404 个状态中，371 个得到参考；原本答错的 904 个状态中，只有 154 个得到参考。最后约 70.7% 的有效状态来自已经答对的当前采样轨迹。这使训练较多落在“已有可行路线，提高确定性”的情形，而非大量修复困难状态。这里不是按原始 base 的题目正确性分组。

第三，当前 loss 只监督 G，但注入通过尾层 attention 也影响 G 外的预测，且 G 外也能立即提交。日志观察到组外 KL 和提交变化随训练增加；它们说明影响范围超过监督范围，不能直接等同于错误率增加。这是值得优先补齐的目标覆盖。

## 7. 下一步建议：保留结构，补 Receiver 监督

首选保留现有组内一致性训练，在同一个已认证参考上增加组外 Receiver 目标，不改推理结构。

对已接受的 π，额外跑一次冻结 Teacher：把整个 G 揭开为 π，读取当前 block 其他 MASK 位置 R 的分布 q_j^{G,π}。沿用产生 π 的那条验证通过续写 Y*，优先选 Teacher top1 等于 Y*_j，且 Teacher 对 Y*_j 的支持比原始状态 q0_j 更强的位置。只在合格 Receiver 上增加：

\[
\mathcal L=\mathcal L_G+\lambda\frac{1}{|R'|}
\sum_{j\in R'}\operatorname{KL}(q_j^{G,\pi}\|p_{\phi,j}),
\qquad \lambda=1\text{ 可作初试}.
\]

这利用的仍然是同一条共同参考，不需要另找一套标签；保留原有组内 loss，监督消息接收者如何受益。原始 q0 已在现有训练中计算，新增目标只需每个有效状态一次 Teacher 前向，推理计算不增加。

数学上的方向是：在 p≈q0 时，如果 q_j^{G,π}(Y*_j)>q0_j(Y*_j)，该目标对参考 logit 的导数为 p_j(Y*_j)−q_j^{G,π}(Y*_j)<0，梯度下降推动这个 logit 上升。这是明确的局部优化方向；共享参数能否实现、是否转化为最终题目得分，仍由实验决定。

廉价起步可以复用现有 525 个状态与续写做离线原型；它是固定数据上的试验，后续正式训练仍刷新 on-policy 状态。现有 injector scale 也可先在 dev 小集比较 1.0 与 0.75，检查能否减少损伤并保留速度收益。不要用这批 test 继续挑参数后再当独立验证。

以当前评分口径，+3–5 个百分点意味着相对 base 净多答对 15–25 题，目前是净 3 题。若能保留现有 32 个修复，损伤数需要从 29 降到至多 17 或 7。这是下一步可以围绕的目标，当前数据不足以保证达到。
